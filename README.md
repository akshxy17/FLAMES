# 🔥 FLAMES Calculator 🔥

A fun and interactive **FLAMES Calculator** that predicts the relationship between two people based on their names. Built with a **HTML/CSS/JavaScript** frontend.

---

## 💡 About the Project

FLAMES is a popular childhood game that stands for:
- **F** – Friends
- **L** – Love
- **A** – Affection
- **M** – Marriage
- **E** – Enemy
- **S** – Sibling

This project allows users to input two names and calculates the FLAMES result based on a logical elimination algorithm. The backend handles business logic and database operations, while the frontend ensures a smooth and user-friendly experience.

---

## 🛠 Tech Stack

### 🚀 Frontend
- HTML
- CSS
- JavaScript

---

## 📌 Features

- 🔤 Input form for entering two names
- 🧮 FLAMES logic calculation using Java
- 💬 Displays the result with a dynamic message
- 🌐 Clean and responsive UI
